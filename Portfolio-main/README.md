## Portfolio

A lightweight, static portfolio built with semantic HTML, CSS, and vanilla JavaScript.

### Local preview

Open `index.html` in a browser or serve this directory with any static file server. There is no build step or package dependency.

### Deployment

The site is designed for static hosting, including Vercel. Keep `index.html`, `style.css`, `script.js`, `favicon.avif`, `robots.txt`, and `sitemap.xml` at the deployment root.

Live site: [portfolio-nu-eight-60.vercel.app](https://portfolio-nu-eight-60.vercel.app/)
